## About

This repository contains practical implementations of various algorithms and concepts studied as part of the **Design and Analysis of Algorithms (DAA) Laboratory**.

The repository covers fundamental algorithmic techniques, including searching, sorting, divide and conquer, greedy methods, dynamic programming, graph traversal, backtracking, and NP-Hard and NP-Complete problems.

All implementations are written in C++ and organized unit-wise for easy reference and practice.

## Laboratory Experiments

| Unit | Topics |
|---|---|
| Unit 1 | Introduction to Algorithms, Linear Search, Bubble Sort, Selection Sort, Insertion Sort |
| Unit 2 | Divide and Conquer, Binary Search, Merge Sort, Quick Sort, Recursive Sorting, Heap Sort, Strassen's Matrix Multiplication |
| Unit 3 | Greedy Method, Fractional Knapsack, Job Sequencing with Deadlines, Prim's Algorithm, Kruskal's Algorithm |
| Unit 4 | Dynamic Programming, Fibonacci, 0/1 Knapsack, Multistage Graph, Floyd-Warshall, Bellman-Ford, Travelling Salesman Problem |
| Unit 5 | Tree Traversals, Graph Representation, Breadth First Search (BFS), Depth First Search (DFS) |
| Unit 6 | Backtracking, N-Queens Problem, Sum of Subsets |
| Unit 7 | NP-Hard and NP-Complete Problems, Exhaustive Search, Branch and Bound, 0/1 Knapsack, Travelling Salesman Problem |
